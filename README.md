# AI Marketing Content Repurposer

A Streamlit web app that turns long-form documents into ready-to-use marketing content. Upload a PDF, PowerPoint, or Word file and get an executive summary, LinkedIn post, and Instagram caption generated by Google Gemini.

## Features

- **Multi-format upload** — Supports PDF, PPTX, and DOCX files
- **Automatic text extraction** — Pulls readable text from documents using [MarkItDown](https://github.com/microsoft/markitdown)
- **AI-generated assets** — Produces:
  - Executive summary (3–4 sentences)
  - LinkedIn post with professional formatting
  - Instagram caption with relevant hashtags
- **Simple UI** — Upload, click generate, and copy the output

## Tech Stack

| Component        | Technology              |
| ---------------- | ----------------------- |
| UI               | Streamlit               |
| Document parsing | MarkItDown              |
| AI               | Google Gemini (`gemini-2.5-flash`) |
| Config           | python-dotenv           |

## Prerequisites

- Python 3.10+
- A [Google AI API key](https://aistudio.google.com/apikey)

## Setup

1. **Clone the repository**

   ```bash
   git clone <your-repo-url>
   cd ai-study-pdf
   ```

2. **Create and activate a virtual environment**

   ```bash
   python -m venv venv
   ```

   On Windows:

   ```bash
   venv\Scripts\activate
   ```

   On macOS/Linux:

   ```bash
   source venv/bin/activate
   ```

3. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

4. **Configure your API key**

   Create a `.env` file in the project root:

   ```env
   GOOGLE_API_KEY=your_api_key_here
   ```

   The `.env` file is gitignored and will not be committed.

## Usage

Start the app:

```bash
streamlit run app.py
```

Then in the browser:

1. Upload a document (PDF, PPTX, or DOCX)
2. Click **Generate Marketing Assets**
3. Review the generated summary, LinkedIn post, and Instagram caption

## How It Works

1. The uploaded file is saved temporarily on disk
2. MarkItDown extracts plain text from the document
3. The text is sent to Gemini with a marketing-focused prompt
4. The AI response is displayed in the Streamlit UI
5. The temporary file is removed after processing
